Smart Stoc AI -SmartStoc AI is a powerful mobile and dashboard system designed for supermarkets to optimize shelf monitoring, track expiration dates, and dynamically calculate discounts.

## 🌟 Key Features
- **AI Expiration Tracker**: Automatically reads and processes expiration dates using computer vision.
- **Dynamic Markdown Engine**: Algorithmic price reduction rules based on remaining shelf life.
- **Stock Alert System**: Automated notifications for structural stock-outs and misplaced items.

## 📱 Tech Stack
- **Frontend**: Flutter (Dart) - Native iOS & Android Mobile Interface
- **Backend**: Python 3 - High-performance business logic
